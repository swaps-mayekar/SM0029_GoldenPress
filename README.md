# Golden Press

Cozy oil-mill management vertical slice for iPhone/iPad (landscape).

## Open in Unity

1. Open this project in **Unity 6000.3.0f1**.
2. Menu: **Golden Press → Setup Scenes And Build Settings** (also configures art sprites)
3. Menu: **Golden Press → Create Default Balance Asset**
4. Press Play on `Assets/Scenes/0_SplashScene.unity`

## Art

Final cozy painted art lives in:

- `Assets/_GoldenPress/Art/` — source backgrounds, props, UI frames
- `Assets/_GoldenPress/Resources/Art/` — runtime-loadable sprites via `ArtCatalog`

Key assets: splash hero, hub & production backgrounds, wooden press, oil tank, family shop, bottle, groundnuts, debris, basket, coin, logo mark, parchment panel frame.

## Vertical slice loop

Receive order → pay processing fee → sorting → processing → bottling → fulfill → earn → unlock oils → endless orders.
