# Golden Press

Cozy oil-mill management vertical slice for iPhone/iPad (landscape).

## Open in Unity

1. Open this project in **Unity 6000.3.0f1**.
2. Menu: **Golden Press → Setup Scenes And Build Settings**
3. Menu: **Golden Press → Create Default Balance Asset**
4. Press Play on `Assets/Scenes/0_SplashScene.unity`

## Vertical slice loop

Receive order → pay processing fee → sorting → processing → bottling → fulfill → earn → unlock oils → endless orders.
